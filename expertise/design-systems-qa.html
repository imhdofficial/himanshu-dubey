THE STANDARD

Testing is where product intent gets verified.

A screen can look correct and still fail in use. My QA process checks whether the implemented product matches its requirements, whether interactions behave correctly under real inputs, and whether fixes remain stable after change.

START WITHRequirements & flow
WRITEScenarios & test cases
EXECUTEFunctional + UI checks
FINISH WITHRetest + regression
WHAT GREAT LOOKS LIKE
01

Understand before testing

Read the requirement, user role, intended flow and expected result first. Without that context, a test can pass while the product still behaves incorrectly.

02

Write cases that can be repeated

A useful test case has a clear precondition, action and expected result so someone else can reproduce the same validation later.

03

Test both UI and behaviour

Check layout, copy, alignment and responsive states alongside actual actions such as submit, paste, validation, navigation and persistence.

04

Include negative and edge paths

Invalid input, missing data, slow responses, interrupted flows and small screens reveal issues that happy-path testing never sees.

05

Report bugs for fast fixing

A useful issue report explains where it happens, how to reproduce it, what was expected and what actually happened.

06

Retest, then regress

After a fix, verify the original problem and then check nearby flows so one correction does not quietly break something else.

PRACTICAL METHOD
01

Read the requirement

Understand the expected behaviour, user role, dependencies and acceptance criteria.

02

Prepare scenarios & cases

Cover the happy path, validation, negative cases, responsive conditions and likely edge behaviour.

03

Execute against the build

Validate visuals and functionality using realistic data, inputs, devices and screen sizes.

04

Log reproducible issues

Capture steps, expected result, actual result, severity and enough context for a developer to act quickly.

05

Retest & run regression

Confirm the fix, recheck related areas and only then treat the issue as closed for release.
