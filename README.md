# Himanshu Dubey — Portfolio

A modern portfolio website showcasing selected product design, frontend development, Shopify, AI interface, and digital product work.

Built as a fully static website using HTML, CSS and JavaScript, and optimized for GitHub Pages.

[himanshu-dubey.com](https://himanshu-dubey.com)

- Custom interactions and motion
- Dedicated project case studies

- Shopify commerce experience
- AI-assisted product interfaces
- Testing & QA approach
- Accessibility and responsive checks
- GitHub Pages compatible

## Selected Work

### AI Product Chatbot
A persistent website chatbot designed and developed for business and product-specific conversations, including product recommendation cards, conversation continuity, response notifications and complete chat controls.

### Loyalty Program
A mobile-first QR-based reward experience designed for simple real-world usage, including OTP verification, reward flows, responsive interaction design and frontend implementation.

### Mewaram
A Shopify ecommerce experience covering storefront UX, product collections, gifting journeys, custom theme sections and a build-your-own combo experience.

### E-Idea Box
An internal digital product designed to simplify employee idea submission, structured review and innovation workflows.
