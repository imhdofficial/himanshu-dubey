THE PROBLEM

Make product help feel native to the website, not bolted on.

The assistant needed to stay useful across navigation, support product discovery visually and handle delayed responses without forcing the user to stare at an open popup. The interface therefore had to manage conversation state, product recommendations and notification behavior as one small product inside the larger website.

ROLEDesign + frontend

WHAT I DESIGNED + BUILT
01

Persistent conversation shell

The chatbot popup remains available across website pages so navigation does not break the active conversation or force the user to restart.

02

Product recommendation cards

When the assistant recommends a product, the answer can render a product card instead of burying the recommendation inside plain text.

03

Complete popup behavior

Minimize, close and start-new-chat states were designed as part of the core interaction model rather than treated as browser-window decoration.

04

Delayed-response notification

If the user minimizes or closes the popup while a response is still being generated, the interface can notify them when the answer becomes available.

05

Frontend state handling

The UI was developed to handle message states and interaction transitions cleanly so the experience feels like a reliable product feature, not a demo.

KEY PRODUCT DETAILS
01

Business-only scope

The assistant is intentionally framed around the business and product knowledge instead of pretending to answer everything.

02

Context continuity

A user can browse another page and return to the assistant without losing the conversational thread.

03

Visual recommendation

Product cards make suggested items scannable and actionable inside the same conversation.

04

Non-blocking wait state

Users are free to continue browsing while a slow response is generated.

05

Clear reset control

Starting a new chat is explicit, so context changes do not become confusing.

06

Mobile-safe popup

The interaction model adapts to smaller screens rather than relying on desktop hover behavior.
